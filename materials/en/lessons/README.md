## Как заниматься

Открой [Fluent Thread](https://itprodavets.github.io/fluent-thread/#materials). Выбирай школу и тему, затем нужный уровень. Чтобы работать без приложения, открой README нужной темы: тексты, диалоги, словарь, правила и ответы доступны прямо в GitHub. Для импорта скачай lesson.json.

Фразы преподавателя и грамматика доступны в самом занятии. В режиме «По навыкам» можно ответить текстом или голосом и повторять полезные фразы. Личные оценки и повторения сохраняются в профиле; файлы материалов не содержат облачных паролей, токенов и аудио преподавателей.
