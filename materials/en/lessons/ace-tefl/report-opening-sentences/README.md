# Отчёт за четыре предложения: цель, плюсы, минусы и рекомендация

Самостоятельное занятие по заданию ACE TEFL. [Полный разбор исходного урока](../reports-and-mirror-town/README.md). Дата относится к исходному уроку; все модели и упражнения ниже — авторские, без исходного аудио.

## Словарь и обороты

### The purpose of this report is to…

Цель этого отчёта —…

The purpose of + noun + is to + base verb. После to не пишем summarising.

Пример: The purpose of this report is to summarise the discussion.

### summarise the discussion about…

кратко изложить обсуждение…

summarise + объект; about + тема. BrE summarise; AmE summarize тоже верно.

Пример: Please summarise the discussion about the new library.

### the proposed scheme

предлагаемый проект

proposed + noun. В данном контексте scheme — проект, не мошенническая схема.

Пример: The proposed scheme could benefit local people.

### One of the main benefits discussed was that…

Одним из основных обсуждавшихся преимуществ было то, что…

one of + the + plural noun; was согласуется с one. discussed = that were discussed.

Пример: One of the main benefits discussed was that the library could offer free study space.

### could create jobs for local people

мог бы создать рабочие места для местных жителей

could + base verb: возможность, а не гарантированный результат.

Пример: The new centre could create jobs for local people.

### The main concern raised was…

Основным высказанным опасением было…

concern raised = concern that was raised. Raise a concern = высказать опасение.

Пример: The main concern raised was the extra traffic.

### the noise it could create

шум, который он мог бы создавать

the noise (that) it could create: that можно опустить, оно объект. Подлежащее it остаётся.

Пример: Residents discussed the noise it could create.

### I would recommend…

Я бы рекомендовал…

recommend + -ing либо recommend that + subject + base verb / should + base verb. Не recommend to approve.

Пример: I would recommend approving the project.

### allow the project to go ahead

разрешить реализацию проекта

allow + object + to + verb; go ahead = состояться / быть реализованным.

Пример: We could allow the project to go ahead.

### provided that…

при условии, что…

provided that + clause; для будущего условия здесь Present Simple, не will.

Пример: The project can go ahead, provided that noise is limited.

### effective measures are taken to…

принимаются эффективные меры, чтобы…

take measures to + base verb; are taken — пассив, важны меры, а не исполнитель.

Пример: Effective measures are taken to protect residents.

### limit noise for local residents

ограничить шум для местных жителей

limit / reduce noise; noise в этом значении неисчисляемое.

Пример: We need measures to limit noise for local residents.

### subject to the implementation of…

при условии реализации…

subject to + noun / -ing; provided that + полное предложение. Не subject to measures are taken.

Пример: Approval is subject to the implementation of noise controls.

### On balance, I would recommend…

Взвесив доводы, я бы рекомендовал…

On balance вводит итоговую оценку обеих сторон; после оборота запятая.

Пример: On balance, I would recommend a small pilot project.

## Как работать · четыре предложения отчёта

Цель: самостоятельно написать четыре начальных предложения формального отчёта. Это авторская практика по заданию ACE TEFL, а не новая расшифровка или цитаты преподавателя.

Задание со слайда: Write an opening sentence for each heading.
Why the report has been written
Benefits of the proposed scheme
Drawbacks of the proposed scheme
Recommendations

Тема — прежнее обсуждение фуд-корта. В записи упоминались рабочие места и шум; полного текста прежних дебатов нет. Условное одобрение ниже — предложенная позиция автора, не установленное решение встречи. Нужны четыре предложения, а не полный отчёт. A1–A2 — подготовительные простые модели, а не образцы экзаменационного формального стиля. Сложнее не обязательно лучше: начинай с B1/B2.

Порядок: прочитай модель → вспомни оборот по переводу → выполни задания без подсказки → напиши четыре своих предложения → сверь смысл, грамматику и источник аргументов. В оценках «Ещё раз / С подсказкой / Самостоятельно» отмечай собственный результат, а не факт открытия текста. Для фраз доступны «Могу использовать» и отложенное повторение. Автоматической оценки свободного отчёта учителем здесь нет.

## Четыре предложения отчёта · A1

Why the report has been written
This report is about a new food court.

Benefits of the proposed scheme
The food court can give local people jobs.

Drawbacks of the proposed scheme
The food court can be noisy.

Recommendations
I think the project is a good idea if it is not too noisy.

### Перевод

Зачем написан отчёт
Этот отчёт о новом фуд-корте.

Преимущества предлагаемого проекта
Фуд-корт может дать местным жителям работу.

Недостатки предлагаемого проекта
Фуд-корт может быть шумным.

Рекомендации
Я думаю, проект — хорошая идея, если он не будет слишком шумным.

## Полезные фразы · конструктор формального отчёта

Авторские обороты для письма; не дословные цитаты преподавателя.

Фраза 1 · The purpose of this report is to…
Перевод: Цель этого отчёта —…
Конструкция: The purpose of + noun + is to + base verb. После to не пишем summarising.
Твой пример для практики: The purpose of this report is to summarise the discussion.

Фраза 2 · summarise the discussion about…
Перевод: кратко изложить обсуждение…
Конструкция: summarise + объект; about + тема. BrE summarise; AmE summarize тоже верно.
Твой пример для практики: Please summarise the discussion about the new library.

Фраза 3 · the proposed scheme
Перевод: предлагаемый проект
Конструкция: proposed + noun. В данном контексте scheme — проект, не мошенническая схема.
Твой пример для практики: The proposed scheme could benefit local people.

Фраза 4 · One of the main benefits discussed was that…
Перевод: Одним из основных обсуждавшихся преимуществ было то, что…
Конструкция: one of + the + plural noun; was согласуется с one. discussed = that were discussed.
Твой пример для практики: One of the main benefits discussed was that the library could offer free study space.

Фраза 5 · could create jobs for local people
Перевод: мог бы создать рабочие места для местных жителей
Конструкция: could + base verb: возможность, а не гарантированный результат.
Твой пример для практики: The new centre could create jobs for local people.

Фраза 6 · The main concern raised was…
Перевод: Основным высказанным опасением было…
Конструкция: concern raised = concern that was raised. Raise a concern = высказать опасение.
Твой пример для практики: The main concern raised was the extra traffic.

Фраза 7 · the noise it could create
Перевод: шум, который он мог бы создавать
Конструкция: the noise (that) it could create: that можно опустить, оно объект. Подлежащее it остаётся.
Твой пример для практики: Residents discussed the noise it could create.

Фраза 8 · I would recommend…
Перевод: Я бы рекомендовал…
Конструкция: recommend + -ing либо recommend that + subject + base verb / should + base verb. Не recommend to approve.
Твой пример для практики: I would recommend approving the project.

Фраза 9 · allow the project to go ahead
Перевод: разрешить реализацию проекта
Конструкция: allow + object + to + verb; go ahead = состояться / быть реализованным.
Твой пример для практики: We could allow the project to go ahead.

Фраза 10 · provided that…
Перевод: при условии, что…
Конструкция: provided that + clause; для будущего условия здесь Present Simple, не will.
Твой пример для практики: The project can go ahead, provided that noise is limited.

Фраза 11 · effective measures are taken to…
Перевод: принимаются эффективные меры, чтобы…
Конструкция: take measures to + base verb; are taken — пассив, важны меры, а не исполнитель.
Твой пример для практики: Effective measures are taken to protect residents.

Фраза 12 · limit noise for local residents
Перевод: ограничить шум для местных жителей
Конструкция: limit / reduce noise; noise в этом значении неисчисляемое.
Твой пример для практики: We need measures to limit noise for local residents.

Фраза 13 · subject to the implementation of…
Перевод: при условии реализации…
Конструкция: subject to + noun / -ing; provided that + полное предложение. Не subject to measures are taken.
Твой пример для практики: Approval is subject to the implementation of noise controls.

Фраза 14 · On balance, I would recommend…
Перевод: Взвесив доводы, я бы рекомендовал…
Конструкция: On balance вводит итоговую оценку обеих сторон; после оборота запятая.
Твой пример для практики: On balance, I would recommend a small pilot project.

## Грамматика урока · четыре функции и точные конструкции

1. Цель отчёта: The purpose of this report is to + verb. Пример: …is to summarise the discussion. После is to здесь инфинитив, не -ing.

2. One of the main benefits was…: one of + существительное во множественном числе, но главный субъект one — единственное число. One of the benefits was… / The benefits were…

3. Обсуждённое не равно доказанному: a benefit discussed / a concern raised — сокращённые относительные конструкции. Полные формы: a benefit that was discussed / a concern that was raised. Они сообщают, что прозвучало в обсуждении.

4. Could + начальная форма: could create / could cause, не could creates / could to create. В этих моделях could обозначает возможный эффект проекта, а не установленный факт. Не нужно механически заменять каждое can на could в любом отчёте.

5. Рекомендация: I would recommend approving the project. Альтернативы: I would recommend that the project be approved / should be approved. Не I would recommend to approve.

6. Разрешить действие: allow + объект + to + глагол. Allow the project to go ahead. Само go ahead здесь означает реализоваться.

7. Условие: provided that + предложение. …provided that measures are taken. При условии о будущем здесь используем Present Simple. Subject to + существительное: subject to noise controls / subject to the implementation of noise controls.

8. Пассив: measures are taken. Take–took–taken. Исполнитель не назван, потому что главное — наличие мер. Noise в этом смысле неисчисляемое: less noise, не fewer noises.

9. Регистр и ясность: в формальном отчёте избегай gonna, lots of good stuff и неподтверждённых уверенных обещаний. Точные простые предложения лучше длинных шаблонов, смысл которых непонятен. Цель задания — четыре начала разделов; полный отчёт обычно требует дальнейшего развития аргументов.

## Грамматика · Отчёт 1 · Узнай функцию

Соотнеси начала с функциями: A The purpose of this report is to…; B The main concern raised was…; C I would recommend…; D One benefit discussed was…
Функции: цель, преимущество, недостаток, рекомендация.

### Образец и самопроверка

Цель — A; преимущество — D; недостаток — B; рекомендация — C. Concern = опасение; recommendation = предложение автора о том, что делать.

## Грамматика · Отчёт 2 · Собери цель

Составь предложение: this report / The purpose of / is / the discussion / to summarise / about the proposed food court.

### Образец и самопроверка

The purpose of this report is to summarise the discussion about the proposed food court.
Перевод: Цель этого отчёта — кратко изложить обсуждение предлагаемого фуд-корта.
Каркас: The purpose of + noun + is to + verb + object.

## Грамматика · Отчёт 3 · Вспомни по переводу

Переведи без образца: «Одним из основных обсуждавшихся преимуществ было то, что фуд-корт мог бы создать рабочие места для местных жителей».

### Образец и самопроверка

One of the main benefits discussed was that the food court could create jobs for local people.
Допустимо: One benefit discussed was that…
Проверь: benefits во множественном числе, was после one, create после could.

## Грамматика · Отчёт 4 · Опиши опасение

Напиши по-английски: «Основным высказанным опасением был шум, который фуд-корт мог бы создавать в районе». Используй concern raised и could.

### Образец и самопроверка

The main concern raised was the noise the food court could create in the neighbourhood.
Вариант с that: …the noise that the food court could create…
Concern raised = concern that was raised; что опасение высказали — не доказательство, что результат неизбежен.

## Грамматика · Отчёт 5 · Исправь типичные ошибки

Исправь: 1 The purpose of this report is summarising the debate. 2 One of the main benefit were new jobs. 3 It could creates jobs. 4 I would recommend to approve the project. 5 Provided that measures will be taken, it can go ahead.
Это специально придуманные ошибки для практики, а не приписанные ученику реплики.

### Образец и самопроверка

1 The purpose of this report is to summarise the debate. 2 One of the main benefits was new jobs. 3 It could create jobs. 4 I would recommend approving the project. / I would recommend that the project be approved. 5 Provided that measures are taken, it can go ahead.
Причины: инфинитив; one of + plural и was; could + base verb; recommend + -ing / that; настоящее время в будущем условии.

## Грамматика · Отчёт 6 · Преобразуй рекомендацию

Перепиши I would recommend approving the project с that. Затем замени provided that noise controls are introduced на subject to + существительное.

### Образец и самопроверка

I would recommend that the project be approved. / …that the project should be approved.
…subject to the introduction of noise controls. / …subject to noise controls.
Provided that + clause, subject to + noun phrase. Это альтернативы, не обязательное усложнение.

## Грамматика · Отчёт 7 · Отдели источник от позиции

Что из этого сообщает прозвучавший аргумент, а что предлагает решение автора? A A participant pointed out that the scheme could create jobs. B I would recommend approving it only if noise is limited.
Можно ли написать, что все участники согласились с B, если этого нет в записи?

### Образец и самопроверка

A передаёт аргумент участника. B — собственная рекомендация автора. Нельзя приписать согласие всем без источника. English: The recommendation is my own proposal, not a confirmed decision of the meeting.

## Грамматика · Отчёт 8 · Напиши с подсказками

Напиши четыре предложения о фуд-корте. Подсказки: The purpose… / One benefit… / The main concern… / I would recommend…
Прежде чем открыть ответ, проверь: все ли четыре функции есть; где факт обсуждения, а где твоя позиция?

### Образец и самопроверка

Возможный B2-ответ:
The purpose of this report is to summarise the discussion about the proposed food court in our neighbourhood.
One of the main benefits discussed was that the new food court could create jobs for local people.
The main concern raised was the noise the food court could create in the neighbourhood.
I would recommend allowing the project to go ahead, provided that effective measures are taken to limit noise for local residents.

Точное совпадение не нужно. Условия о шуме — предложенная собственная рекомендация. Если ты против проекта, можно написать: I would recommend postponing the project until effective noise controls are agreed.

## Грамматика · Отчёт 9 · Перенеси навык на новую ситуацию

Новая вымышленная учебная ситуация: обсуждали публичную библиотеку. Польза — бесплатные места для учёбы; опасение — расходы на обслуживание. Напиши четыре предложения под теми же заголовками. Сам выбери рекомендацию. Это не сведения с урока.

### Образец и самопроверка

Возможный ответ:
The purpose of this report is to summarise the discussion about the proposed public library.
One benefit discussed was that the library could provide free study space for local people.
The main concern raised was the cost of maintaining the building.
I would recommend approving the project, provided that a realistic maintenance budget is agreed.

Перевод: цель — изложить обсуждение; польза — бесплатное место для учёбы; опасение — стоимость содержания; рекомендация — одобрение при согласованном реалистичном бюджете. Другие обоснованные рекомендации тоже верны.

## Грамматика · Отчёт 10 · Напиши без опор и повтори

Сначала без шаблонов напиши четыре предложения о фуд-корте. Затем придумай свой проект и повтори структуру с новой лексикой. Проверь: purpose; reported benefit; reported concern; own recommendation. Оцени себя только после собственной попытки.

### Образец и самопроверка

Контроль: 1) В каждом предложении одна понятная функция. 2) Нет придуманного единогласного решения. 3) One of the benefits was; could + verb; recommend + -ing / that; provided that + clause. 4) Твой новый проект и новые аргументы обозначены как учебная ситуация.
Если пришлось подсмотреть — «С подсказкой». Если снова не получилось — «Ещё раз». Если написал самостоятельно и прошёл проверку — «Самостоятельно». Это самооценка, не автоматическая проверка грамматики.
