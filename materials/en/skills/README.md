# English skills · Навыки английского

[Catalog](catalog.json) connects skills to dialogues from different schools. It contains practice questions, model replies and phrases with their source context. Review marks belong to each learner's profile.

In the app open [Материалы → По навыкам](https://itprodavets.github.io/fluent-thread/#materials/skills). Read the dialogue, answer by text or voice, then use the phrase cards for recall. «Могу использовать» and «Повторить позже» update personal repetition state.
