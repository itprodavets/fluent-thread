# Единый прогресс текущего профиля

Статус: утверждено пользователем 22 ноября 2026; реализация в текущем чате.

## Задача

Показать на странице «Прогресс», сколько слов, фраз, диалогов и упражнений пользователь уже освоил и какие ошибки исправил. Сохранить гостевое локальное обучение, разделение профилей и существующую синхронизацию. Не смешивать загруженный контент с освоенным и не создавать серверный сбор учебных ответов.

## Подход

Вычислять сводку из текущего Study: словарь, результаты, материалы, завершённые сессии и карточки ошибок. Отдельный изменяемый счётчик мог бы расходиться с данными после повторного импорта, удаления или синхронизации; новый журнал всех событий увеличил бы базу и не восстановил бы отсутствующую историю. Поэтому выбран вычисляемый обзор с минимальным сохранением недостающих фактов успешного завершения.

## Экран

Сверху: имя текущего профиля либо «Без входа · этот браузер», выбранный язык, статус хранения.

Сводка:
- Словарные карточки: включая выражения; отдельно показан входящий в них поднабор известных фраз из уроков, навыков и сохранённых реплик. Не угадывать вид карточки по пробелам: это ненадёжно для разных языков. Общую сумму этих двух чисел не показывать.
- Диалоги: уровни считаются отдельными версиями. Завершённый собственный диалог считается выполненной практикой, а не автоматически выученным чужим диалогом.
- Упражнения: выполненные с оценкой; открытие ответа без оценки не считается освоением.
- Тексты и другие материалы: отдельная строка, чтобы результаты чтения и свободной практики не исчезли из сводки.
- Ошибки: не проверял / ещё исправляю / исправил с подсказкой / исправил самостоятельно; отдельный признак наступившего повторения.

У учебных единиц: всего, ещё не пробовал, изучаю (retry / assisted), самостоятельно (последняя явная оценка independent), пора повторить (дополнительный признак, пересекающийся с освоенными и изучаемыми). Подписи объясняют, что «самостоятельно» — последний результат, а не гарантия вечного знания. Устное, письменное и выбор ответа по возможности показываются раздельно; правильный выбор из вариантов не выдаётся за самостоятельную речь.

Ниже: раскрываемые списки по категориям и статусу; у ошибок исходная реплика, исправление, объяснение и последний собственный ответ, ссылка на повторение. Количество в списке совпадает со сводкой. Карточки новых импортированных ошибок без попытки не считаются исправленными. Список ограничен страницами/порциями, чтобы большой словарь не замедлял телефон.

Существующий график активности остаётся отдельным: количество попыток за период отличается от количества освоенных уникальных единиц за всё время. Накопленные исправления входят в сводку. Старые ошибки без дат не приписываются выдуманным дням графика.

## Сохранность и профиль

Обзор только читает Study открытого ProfileStore; не читает чужие профили и не объединяет гостя с вошедшим аккаунтом. Локальный прогресс виден с существующим предупреждением о копии. Облако работает по ранее выбранной политике. Отсутствие попыток честно показывает ноль освоенных даже при большом импортированном словаре. Исходные результаты, интервалы, ответы и идентификаторы сохраняются. Нет новой аналитической отправки на сервер.

## Проверка

Тесты охватывают все категории, фразы-поднабор без удвоения, разные уровни диалога, просроченное самостоятельное повторение, retry после успеха, исправление с подсказкой, карточку ошибки без попытки, удалённые/архивные материалы, разные языки и два независимых профиля. Проверить сериализацию и синхронизацию без изменения старых результатов. Проверить большой словарь, пустой гостевой профиль и мобильный экран. Не ставить оценки реальным материалам пользователя для проверки интерфейса. Закоммитить, опубликовать и проверить main и живой сайт.
